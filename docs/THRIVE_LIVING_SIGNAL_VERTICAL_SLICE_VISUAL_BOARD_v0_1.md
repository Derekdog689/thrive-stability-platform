# THRIVE Living Signal Vertical Slice Visual Board v0.1

Date: 2026-09-30
Status: review-only visual specification
Parent: THRIVE Vertical Proving Slice v0.1
Production impact: none

## Purpose

Define the eight screen states that the next visual board must show using the Living Signal direction.

## Required states

1. Wellness check-in showing an explicit Recovery Support need.
2. Wellness return with four concrete paths:
   - Find a meeting
   - Read something
   - Connect with someone
   - Build a routine
3. Today after that Wellness check-in, carrying Recovery Support forward.
4. Recovery Support path chooser.
5. Contextual Recovery Resources screen using real verified source types.
6. Meeting-finder / meeting-result treatment.
7. Follow-up asking specifically about the chosen action.
8. Story showing the participant-confirmed thread carried forward.

## Visual requirements

- mobile-first;
- Android-friendly proportions;
- Living Signal layered depth;
- brighter daytime atmosphere;
- deeper evening variant where useful;
- lane-specific accents;
- completion / movement visible without reading a full paragraph;
- no hospital-green dominance;
- no generic white-card wall;
- no childish trophies;
- no fake clinical dashboard;
- actual visual personality.

## Important mock-data rule

Direct meeting cards on the board may use clearly illustrative sample meeting names/times to show the intended interaction, but production must use live verified sources or official finders.

The board is a UX target, not evidence that those exact meetings exist.
