# THRIVE Today Route Product Correction Candidate v0.1

## Status

Review-only participant-experience candidate.

## Purpose

Reshape the Today route from a finance-dominant dashboard into a cross-module
participant home.

## Preserved behavior

- Supabase authentication gate;
- shared THRIVE navigation;
- participant name resolution;
- connected financial source count;
- participant-owned transaction count;
- recorded outflow;
- current budget period;
- latest statement period;
- participant-safe observational language.

## Product changes

- Wellness, Goals, and Support become the first daily pathways;
- financial information becomes one contained summary section;
- My Program, Reports, and Budget remain directly accessible;
- visible development-boundary language is removed;
- no write control is added;
- no database query or schema is changed.

## Frozen boundaries

- no database changes;
- no write activation;
- no Johnny or real participant data changes;
- no automatic Support request;
- no financial conclusion or behavioral judgment;
- no Trust Engine synchronization;
- no deployment.

## Review questions

1. Does Today feel like a person-centered home rather than a finance dashboard?
2. Is the financial summary useful without dominating the page?
3. Are Wellness, Goals, and Support understandable as separate choices?
4. Does the route avoid technical and laboratory-style language?
5. Does the mobile layout remain clear and calm?

## Exact next gate

Review the Today route locally on desktop and narrow mobile widths.

Do not commit until the visible layout and wording are approved.
