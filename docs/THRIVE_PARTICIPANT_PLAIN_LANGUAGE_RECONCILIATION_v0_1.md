# THRIVE Participant Plain-Language Reconciliation v0.1

## Status

Participant-facing copy reconciliation candidate installed locally.

## Scope

This pass changes wording and Today-page navigation only.

It does not change schema, participant write permissions, financial calculations,
RLS, bank connections, Trust Engine boundaries, program membership, or stored data.

## Main changes

- shorter Today introduction;
- connected accounts and recent account activity wording;
- simpler recorded-outflow helper text;
- shorter Budget and Wellness introductions;
- reduced Goals and Support scaffolding language;
- simpler Reports labels;
- direct Today links to Wellness, Goals, and Support.

## Product language rule

Use plain words first, one idea per card, short explanations, and technical or
authority boundaries only where they are needed.

## Frozen boundaries

- no schema;
- no writes;
- no real bank connection;
- no Johnny data;
- no Trust Engine synchronization;
- no push or deployment.
